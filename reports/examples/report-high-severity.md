### 2. 🟠 Reentrancy in withdraw()

**ID:** `finding-001`  
**Rule:** `SC-REENT-01`  
**Severity:** HIGH  
**Confidence:** high

#### Description

The withdraw function updates the balance after making an external call, allowing an attacker to recursively call withdraw before the balance is updated.

#### Location

- **File:** `contracts/SimpleBank.sol`
- **Lines:** 27-38

#### Impact

Attacker can drain contract funds through recursive calls

**Likelihood:** high

#### Recommendation

Apply the checks-effects-interactions pattern by updating balances before making external calls, or use OpenZeppelin's ReentrancyGuard.
